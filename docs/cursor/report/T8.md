# T8 — AstrBot one-platform connect

**Date:** 2026-08-19  
**Owner:** Developer 2  
**Status:** Done (live AstrBot WebUI on `:6185`; Telegram connect is **mock** until a bot token exists)

## What shipped

`GET /api/v1/messaging/platforms` + `POST /api/v1/messaging/telegram/connect`.

- AstrBot is **messaging only** (`role: messaging`). No Goals/Use loop.
- Connect without `TELEGRAM_BOT_TOKEN` still returns a connected card + **MCP/source row**
- `send_message` is high-impact: invoke without `confirm=true` → `confirmation_required`
- Bot tokens never appear in JSON
- Live dashboard: http://localhost:6185

If `TELEGRAM_BOT_TOKEN` + dashboard auth are set, the adapter POSTs AstrBot `/api/config/platform/new`; otherwise it stays mock (spec-allowed).

## How we verified

```powershell
cd backend
pytest -q
# GET  /api/v1/messaging/platforms
# POST /api/v1/messaging/telegram/connect
# GET  /api/v1/messaging/sources
# POST /api/v1/mcp/invoke  {"tool":"send_message","args":{"text":"hi"}}
```

| Check | Result |
|-------|--------|
| pytest | **34 passed** |
| Platforms | `telegram` + `discord`, `mode: live`, `role: messaging` |
| Connect card | **Telegram connected (mock)** + `sourceId` + `mcpServerId` |
| Invoke without confirm | `ok: false`, `confirmation_required` |
| Invoke with `confirm: true` | `ok: true`, `{ "delivered": true }` |
| AstrBot WebUI | HTTP 200 |
| Tokens in JSON | none |
