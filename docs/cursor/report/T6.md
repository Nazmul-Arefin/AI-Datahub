# T6 — MCP registry + gateway invoke

**Date:** 2026-08-19  
**Owner:** Developer 2  
**Status:** Done (against the **live** MCP gateway sidecar on `:8080`, with Nango / Memory Core / Harness / AstrBot up)

## What shipped

Register tools from one GitHub connection, invoke through `MCPService` / `MCPGateway`, list allowed tools on `AgentService` with **no tokens**.

- `POST /api/v1/mcp/register` `{ connectionId, name }` → registry row (`serverId`, tools)
- `GET /api/v1/mcp/servers/{id}/tools` → `list_repos`, `get_user`
- `POST /api/v1/mcp/invoke` → JSON result; credentials injected **inside** the gateway only
- `GET /api/v1/agents/tools` → names/ids only
- Audit to sidecar `/data/mcp_audit.jsonl` (and `backend/data/mcp_audit.jsonl` in mock). **Dev1 has no `mcp_audit_events` table yet.**

Invoke is still a **stub** (no live GitHub API call). Completing OAuth in Nango is still T5 leftover / T9 scale.
