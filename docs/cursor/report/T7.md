# T7 — ContextBuilder + AgentService → Harness

**Date:** 2026-08-19  
**Owner:** Developer 2  
**Status:** Done (live `dsh web` RPC on `:3080`)

## What shipped

`POST /api/v1/agents/runs` builds context (goal id + memories + allowed MCP tool names) and starts a DeepSeek Harness session.

- `ContextBuilder.build` / `format_prompt` — goal, memories, tool names (never tokens)
- `HarnessClient` — `session.create` → `session.selectModel` (`deepseek-v4-pro`) → `session.prompt` → `session.history`
- `FallbackLoopAdapter` behind the same `AgentService` interface if Harness RPC fails (uses `LLMService`)
- Run records in `backend/data/agent_runs.jsonl` (**Dev1 has no `agent_runs` table yet**)
- Routers still do not import Harness / AstrBot / Nango

Compose DNS (`http://agent-harness:3080`) is 403 unless the RPC `Host` header is `127.0.0.1:3080` (dsh loopback trust fence). The adapter sets that header.
